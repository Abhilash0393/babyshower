Optional: add an instrumental MP3, OGG, or WAV that you supplied or are licensed to play.
Set DISPLAY_MUSIC_FILE to its filename in the private .env file (for example,
DISPLAY_MUSIC_FILE=instrumental.mp3). The admin Big Screen Experience section can then
enable or disable it. The display requires a user tap before audio playback; missing or
unsupported audio never interrupts slideshow or prediction results. Music files are
excluded from Git by default.
